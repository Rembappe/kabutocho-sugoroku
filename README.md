# 浦島太郎投資伝説

亀に連れられてやってきた竜宮城の取引所で、どこかで見たような会社の株を売り買いして資産を増やす、すごろく式の投資学習ゲームです。

- 1ターン＝2週間。決算、配当、景気の波、金融危機などが起きる
- 株価は「会社の利益 × 市場の気分（PER）」で動く
- 特定口座とNISA（成長投資枠・つみたて投資枠）、税金20.315%を体験できる
- 友達とオンライン対戦（部屋コード＋名前＋数字4桁の合言葉）。全員が同じ相場を体験し、進めるペースは各自の自由
- 1台を交代で回して遊ぶこともできる

## 遊び方

GitHub Pages で公開した `index.html` をブラウザで開くだけです。

## 仕組み

- 全員の画面で同じ相場になるように、部屋ごとの乱数シードから相場を再現しています
- 部屋の進行と各プレイヤーの口座は Firebase Cloud Firestore に保存しています
- Firestore のセキュリティルールは `firestore.rules` にあります（Firebase コンソールの Firestore →「ルール」に貼り付けて公開）

## 注意

非営利の学習用ゲームです。登場する会社名・株価・ニュースはすべて架空のもので、実在の企業や団体とは関係ありません。実際の投資判断には使わないでください。
